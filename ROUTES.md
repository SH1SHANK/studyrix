# Studyrix Routes

Last reviewed: 2026-02-10

## App Routes

- `/` Study materials hub
- `/resources` Study materials hub
- `/resources/course/[courseID]` Course folder browser
- `/course/[courseID]` Course folder browser (alias)
- `/resources/offline` Saved materials
- `/offline` Saved materials (alias)
- `/resources/downloads` Downloads and saved files
- `/downloads` Downloads and saved files (alias)
- `/resources/settings` Study materials settings
- `/settings` Study materials settings (alias)
- `/launchpad` Launchpad community
- `/privacy` Privacy and disclaimer

## System Routes

- `/sitemap.xml` Sitemap
- `/robots.txt` Robots policy

## API Routes

- `/api/resources/courses` Courses list
- `/api/resources/filters` Department + semester filters
- `/api/resources/search` Drive search
- `/api/resources/drive` Drive folder listing
- `/api/resources/drive/file` Drive file fetch
